## Описание
Приложение с графическим интерфейсом для генерации случайных паролей.
Позволяет:
- Выбрать длину пароля (от 4 до 32 символов)
- Выбрать типы символов: цифры, буквы, спецсимволы
- Сохранять историю сгенерированных паролей в JSON
- Копировать пароль в буфер обмена
- Управлять историей (очистка, удаление записей)

## Технологии
- Python 3
- Tkinter (GUI)
- Random (генерация)
- JSON (хранение истории)
